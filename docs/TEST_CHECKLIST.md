# Test Checklist

## Старт

- [ ] Открывается стартовый экран.
- [ ] Кнопка “Начать карьеру” работает.
- [ ] Карьера стартует без задержки.
- [ ] Стартовый путь сразу корректный.

## Бои

- [ ] В России 3 боя.
- [ ] В Мексике 3 боя.
- [ ] В Японии 3 боя.
- [ ] Улица даёт 3 боя.
- [ ] Любители дают 3 боя.
- [ ] Профи дают 3 боя.
- [ ] Бой открывает окно результата.
- [ ] После боя меняется рекорд.
- [ ] После боя неделя увеличивается.

## Неделя

- [ ] Кнопка “Следующая неделя” работает.
- [ ] Тренировка работает.
- [ ] После тренировки растёт один навык.
- [ ] Страница не зависает.

## Рейтинг

- [ ] Фильтр страны работает.
- [ ] Фильтр пути работает.
- [ ] Карточка бойца открывается.
- [ ] Игрок отображается в рейтинге.

## Мир

- [ ] Вкладка “Мир” открывается.
- [ ] Сборная страны отображается.
- [ ] События недели появляются после нескольких недель.

## Переходы

- [ ] Игрок может перейти street -> amateur.
- [ ] Игрок может перейти amateur -> street.
- [ ] Игрок может перейти amateur -> pro.
- [ ] После pro нельзя перейти в amateur.
- [ ] После pro -> street нельзя вернуться в pro.

## Сохранения

- [ ] После перезагрузки карьера сохраняется.
- [ ] Сброс карьеры очищает сохранение.
