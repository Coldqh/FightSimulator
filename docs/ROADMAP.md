# Roadmap

## 0. Clean Runtime

Статус: сделано.

- быстрый запуск;
- чистый runtime;
- нет монолитного index с тысячами строк логики;
- старые тяжёлые файлы не подключаются.

## 1. MVP-карьера

Статус: сделано.

- старт карьеры;
- выбор страны;
- выбор пути;
- 3 боя;
- тренировка;
- смена недели;
- рекорд;
- рейтинг;
- карточка бойца.

## 2. Лёгкая экосистема NPC

Статус: частично сделано.

- NPC проводят бои каждую неделю;
- меняются рекорды;
- рейтинги двигаются;
- часть NPC меняет путь;
- события недели показываются во вкладке мира.

Следующий слой:

- закрепить важных знакомых NPC;
- добавить метку “одноклубник с первой недели”;
- дать знакомым бойцам заметный карьерный путь.

## 3. Переходы между путями

Статус: базово сделано.

- street -> amateur;
- amateur -> street;
- amateur -> pro;
- после pro нельзя в amateur;
- после pro -> street нельзя обратно в pro.

Следующий слой:

- экран смены пути;
- объяснение причин перехода;
- предупреждения перед необратимым решением.

## 4. Боевая система

Статус: простая модель.

Сейчас:

- быстрый расчёт результата;
- KO/TKO или решение;
- изменение рекорда;
- окно результата.

Дальше:

- раунды;
- карточки судей;
- план боя;
- различия правил улицы, любителей, профи.

## 5. Рейтинги и сборная

Статус: базово сделано.

- фильтр по стране;
- фильтр по пути;
- состав сборной страны;
- резерв сборной.

Дальше:

- чемпион страны;
- топ мира;
- место игрока в очереди на сборную.

## 6. Вернуть глубину без старого хаоса

Порядок возврата систем:

1. стили боя;
2. клубы;
3. тренеры;
4. турниры;
5. травмы;
6. медиа;
7. отношения;
8. история мира.

Каждый слой добавляется только после проверки скорости.
