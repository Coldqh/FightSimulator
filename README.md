# Fight Simulator

Version: `tournament-ranks-save-2.2.4`

Патч чинит турнирный слой, ранги, новости, имена и сохранение на iPhone PWA.

## Главное

- Один слой турниров для NPC и игрока.
- Континентальные турниры разделены по настоящим континентам.
- Новости турниров больше не дублируются.
- Город/область/регион/страна выводятся в новостях для страны и веса игрока.
- Любительские разряды показываются по OVR.
- Уличные/профи-статусы показывают условия, а не расплывчатые описания.
- Автосмена чемпионов по OVR отключена.
- Сохранение дополнительно пишется в IndexedDB.
- Новый логотип Fight World с двумя перчатками.
